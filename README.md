# Rare Logos Vault

[![License: Unlicense](https://shields.io)](http://unlicense.org)
[![PRs Welcome](https://shields.io)](http://makeapullrequest.com)

A professional, open-source digital vault dedicated to collecting, preserving, and restoring rare, obscure, or hard-to-find software logos. Many vintage, legacy, or niche software products lack high-resolution assets, proper vector formats (SVG), or transparent alternatives. This repository serves as a centralized archive to keep these technology identities alive.

---

## Key Features

* **Multi-Format Storage:** Every logo entry aims to provide both scalable vector graphics (SVG) and high-resolution raster (PNG) formats.
* **Format Flexibility:** We accept all high-quality variations, keeping accessibility open for both designers and developers.
* **Pixel-Perfect Restoration:** Low-res, pixelated, or non-transparent original assets are meticulously traced, cleaned, and updated.
* **Community Driven:** An open ecosystem where tech enthusiasts and designers can preserve software history together.

## Repository Structure

To keep the vault organized, scalable, and easy to navigate, files are structured by category, followed by the software name:

```text
rare-logos-vault/
├── logos/
│   ├── social-media/
│   │   ├── orkut/
│   │   │   ├── logo.svg
│   │   │   └── logo.png
│   │   └── ...
│   ├── operating-systems/
│   │   ├── windows-longhorn/
│   │   │   ├── logo.svg
│   │   │   └── logo.png
│   │   └── ...
│   ├── development-tools/
│   └── ...
├── LICENSE
└── README.md
```

## Asset Guidelines

To maintain the high quality of this archive, please ensure that contributed logos meet the following criteria:

| Attribute | Specification / Requirement |
| :--- | :--- |
| **SVG Files** | Clean vector paths, grouped objects, and zero embedded raster images. |
| **PNG Files** | High-resolution (minimum width of 512px), transparent background, and optimized compression. |
| **Naming Convention** | Files must be named strictly as `logo.svg` and `logo.png` inside the specific software folder. |
| **Originality** | Must match the official or historically accurate colors and shapes of the target software. |
